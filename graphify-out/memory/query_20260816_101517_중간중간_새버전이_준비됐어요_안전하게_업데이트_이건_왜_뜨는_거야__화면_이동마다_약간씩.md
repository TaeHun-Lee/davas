# Q: 중간중간 새버전이 준비됐어요 안전하게 업데이트 이건 왜 뜨는 거야? 화면 이동마다 약간씩 뜨는데 이거 웹 버전인데 이게 왜 떠?

## Answer

Expanded from original query via vocab: [pwa, service, update, consent, controller, offline, refresh, version, app, web]. Davas는 루트 레이아웃에서 PwaStatus를 모든 브라우저 페이지에 렌더링하고, PwaStatus는 설치 여부와 무관하게 /sw.js를 서비스 워커로 등록한다. 새 서비스 워커가 waiting 상태이거나 updatefound 뒤 installed 상태가 되면 새 버전 안내를 표시한다. 안전하게 업데이트 버튼은 waiting 워커에 SKIP_WAITING을 보내고 controllerchange 뒤 새로고침한다. 대기 워커가 활성화될 때까지 registration.waiting이 유지되고 닫기 또는 세션 억제가 없어서, 전체 문서 이동으로 루트가 다시 마운트되거나 고정 배너가 이동 중 유지될 때 반복해서 뜨는 것처럼 보인다. 이는 웹에서도 가능한 PWA 동작이지만 반복 노출은 현재 UX 결함이다. 일반 웹에서는 다음 로드에 조용히 갱신하거나 세션당 한 번만 알리고, 작성 중에는 갱신을 유예하는 방식이 적합하다.

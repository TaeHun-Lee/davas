## Answer

Expanded from original query via graph vocab: [recordcomposer, rating, star, back, button, nav, draft, save, screen]. RecordComposer renders the shared rating control and persists a per-user session draft. CoreUi BackHeader owns history navigation, while RecordComposer previously overrode it with an inline discard state. The appropriate implementation is a native half-step range input with star feedback, URL-synchronized compose steps, and BackHeader router.back with a root fallback.

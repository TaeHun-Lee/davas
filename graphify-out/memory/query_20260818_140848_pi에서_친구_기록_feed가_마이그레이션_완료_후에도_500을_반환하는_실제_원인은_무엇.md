# Q: Pi에서 친구 기록 feed가 마이그레이션 완료 후에도 500을 반환하는 실제 원인은 무엇인가

## Answer

PostgreSQL 로그에서 DiariesService.feed가 생성한 FRIENDS visibility raw predicate의 닫는 괄호 누락으로 distinctAlias 앞 syntax error가 발생함을 확인했다. raw predicate에 닫는 괄호를 추가하고 괄호 균형 회귀 테스트를 추가했다.

## Outcome

- Signal: corrected
- Correction: 초기 마이그레이션 누락 추정은 Pi migration:show에서 전부 적용됨이 확인되어 기각됐고 실제 원인은 feed SQL 구문 오류였다.

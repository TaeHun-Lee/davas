# 제품 요구사항 구현 추적표

이 문서는 [제품 기준](README.md), [제품 요구사항 상세 설계](planning/product-requirements-analysis.md), [기술 아키텍처 상세 설계](planning/technical-architecture-analysis.md), [추천 전략 상세 설계](planning/recommendation-strategy-analysis.md)의 MVP 요구사항을 코드와 연결하는 유지보수용 추적표다. 기능 계약이나 근거 파일이 바뀌면 같은 변경에서 해당 행의 상태와 근거를 함께 갱신한다.

상태는 다음 기준으로 사용한다.

- **구현됨**: MVP의 서버·웹 경로와 핵심 실패 상태가 연결되어 있고 국소 테스트 근거가 있다.
- **부분**: 핵심 경로는 있으나 문서가 요구하는 보조 기능, 자동 실행, 운영 검증 또는 일부 상태가 남아 있다.
- **외부 공급자 필요**: 내부 경계와 저장 계약은 있으나 출시 품질은 외부 데이터·전달 사업자나 이용 조건 확정에 달려 있다.
- **미구현**: 기획 문서가 요구하지만 서버·웹 어디에도 아직 없다.

## 출시 전 별도 검증 경계

다음 항목은 코드 매핑만으로 완료 판정하지 않는다.

- 실제 PostgreSQL에서 migration up/down, FK·check 제약, 마지막 자리 동시 초대 수락을 검증한다.
- 2명·3명·5명 공간으로 모바일 키보드, 스크린리더 레이블, 대비와 장시간 합의 흐름을 확인한다.
- 한국 작품·OTT/극장 공급자의 정확도, 이용 약관, 출처 표시와 만료/장애 폴백을 검증한다.
- 아웃박스 소비 재시도, 중복 전달, 적체 경보와 계정 삭제의 검색·캐시·백업 전파를 검증한다.
- 기존 친구·일기·추천 클라이언트와 `/diary`·`/records` 딥링크에 대한 전수 회귀는 최종 통합 단계에서 수행한다.
